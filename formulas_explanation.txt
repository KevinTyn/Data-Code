InSAR Mosaic 核心公式与解释
（可直接复制到 Word，配合公式编辑器使用）
============================================================

本文档对应脚本 1224_new2.py 中 "加权差分残差" 与 "轨内拟合残差" 的计算逻辑。
每条公式给出：(1) Word 线性格式 (2) LaTeX 对照 (3) 物理含义解释。

------------------------------------------------------------
一、轨内拟合残差 (In-track Fitting Residual)
------------------------------------------------------------

【公式】
wrmse_k = sqrt( Σ w_{k,i} · (v_{k,i} - f_k(t_i))^2  /  Σ w_{k,i} )

【LaTeX】
\mathrm{wrmse}_k = \sqrt{\frac{\sum_i w_{k,i} \big(v_{k,i} - f_k(t_i)\big)^2}{\sum_i w_{k,i}}},\quad k=1,2

【变量解释】
  v_{k,i}   -- 第 k 景影像在像元 i 处的形变速率值 (单位: m/yr)
  f_k(t_i)  -- 联合模型对该像元时刻 t_i 的拟合值
              Const 模型:  f(t) = α （常数）
              Linear 模型: f(t) = a + b·t （线性趋势）
  w_{k,i}   -- 像元 i 的权重，由相干性导出: w = coherence²

【物理含义】
衡量每景影像内部所有像元的拟合质量。值越小说明该轨数据越"干净"，
模型越能解释其内部变化。该残差只反映单轨自身的时间序列一致性，
不涉及两轨之间的差异。

------------------------------------------------------------
二、加权差分残差 (Weighted Differential Residual)
------------------------------------------------------------

【2-1 加权差分 RMSE】

【公式】
wrmse_diff = sqrt( Σ w_i^Σ · (f_1(t_i) - f_2(t_i))^2  /  Σ w_i^Σ )

【LaTeX】
\mathrm{wrmse}_{\mathrm{diff}} = \sqrt{\frac{\sum_i w_i^{\Sigma} \big(f_1(t_i) - f_2(t_i)\big)^2}{\sum_i w_i^{\Sigma}}}

【2-2 加权差分偏差】

【公式】
bias_diff = Σ w_i^Σ · (f_1(t_i) - f_2(t_i))  /  Σ w_i^Σ

【LaTeX】
\mathrm{bias}_{\mathrm{diff}} = \frac{\sum_i w_i^{\Sigma} \big(f_1(t_i) - f_2(t_i)\big)}{\sum_i w_i^{\Sigma}}

【变量解释】
  f_1(t_i)           -- 影像1 在像元 i 处联合模型的拟合速率
  f_2(t_i)           -- 影像2 在像元 i 处联合模型的拟合速率
  w_i^Σ = w_{1,i} + w_{2,i}  -- 两景影像在该像元的总权重

【物理含义】
这是两景影像拼接的核心质量指标：
  - wrmse_diff 衡量的是两景影像在重叠区"整体趋势"的系统性差异。
    如果两轨数据本身自洽，f_1 和 f_2 应该高度一致，wrmse_diff 很小。
    如果重叠区存在轨道或大气残留误差，wrmse_diff 会偏大。
  - bias_diff  衡量两轨之间存在多大的整体"平移偏差"。
    正值说明影像1整体偏大，负值说明影像2整体偏大。
    这项偏差最终会作为常数校正项写入平差模型。

三、联合模型的构建原理
------------------------------------------------------------

不同于"先各自建模再比较"的简单做法，本脚本采用联合约束建模。
核心思想：两个影像共享同一个时间序列 t，同时加入耦合正则项 λ，
使得两轨的拟合值 f_1(t) 和 f_2(t) 在约束下趋近一致。

【Const 模型的正规方程】
┌                                          ┐ ┌    ┐   ┌                                      ┐
│  Σw_1 + λΣw^Σ          -λΣw^Σ           │ │ α_1 │ = │  Σw_1·v_1 + λΣw^Σ·v_2                │
│  -λΣw^Σ                Σw_2 + λΣw^Σ     │ │ α_2 │   │  Σw_2·v_2 + λΣw^Σ·v_1                │
└                                          ┘ └    ┘   └                                      ┘

【Linear 模型的正规方程】
┌                  ┐ ┌        ┐   ┌                      ┐
│  A_11    A_12    │ │  β_1   │ = │  b_1                 │
│  A_21    A_22    │ │  β_2   │   │  b_2                 │
└                  ┘ └        ┘   └                      ┘

其中:
  β_k = [a_k, b_k]^T                              (截距和斜率)
  X = [1, t]                                        (设计矩阵)
  A_kk = X^T·W_k·X + λ·X^T·W^Σ·X
  A_12 = A_21^T = -λ·X^T·W^Σ·X
  b_k = X^T·W_k·v_k + λ·X^T·W^Σ·v_{k'}

【变量解释】
  λ (lambda) -- 耦合正则化参数，控制两轨拟合值的一致性强度
       λ 越大 → 强制 f_1 ≈ f_2，牺牲单轨拟合精度换取两者一致
       λ 越小 → 两轨各自独立拟合，差异保持原始状态
  本脚本通过 Pareto 前沿在多个 λ 值中自动选优。

四、IGG-III 鲁棒迭代权重
------------------------------------------------------------

在 ALS 迭代过程中，每轮根据残差重新分配权重，剔除异常值。

【公式】
设 r_i = v_i - f(t_i)，sigma = median(|r_i|) / 0.6745
归一化残差:  bar_r_i = |r_i| / sigma

                 ┌  1,                               bar_r_i ≤ k_0
   p_i^{(new)} = ┤  p_i^{(0)}·(k_0/bar_r_i)·((k_1-bar_r_i)/(k_1-k_0))^2,   k_0 < bar_r_i ≤ k_1
                 └  0,                               bar_r_i > k_1

其中 k_0=1.5, k_1=3.5 为经验阈值。

【物理含义】
  在迭代中，残差过大的像元权重逐步降低甚至归零，
  实现抗差估计，避免局部异常值污染整轨的拟合参数。

------------------------------------------------------------
五、空间斜面拟合残差 (RANSAC Spatial Ramp)
------------------------------------------------------------

时序对齐完成后，对两轨残差图做空间多项式拟合，消除轨道残余 ramp。

【公式】
Δv(x,y) = c_0 + c_1·x + c_2·y + ε

RMSE_spatial = sqrt( (1/N_inlier) · Σ (Δv_i - c_0 - c_1·x_i - c_2·y_i)^2 )

【变量解释】
  Δv(x,y) = v_1 - (scale·v_2 + offset)    -- 两轨时序对齐后的像元级残差图
  x, y     -- 像元相对于参考中心的平面坐标 (经差/纬差)
  N_inlier -- RANSAC 内点个数

【物理含义】
  即使时序模型对齐了整体趋势，两轨数据在空间维度上仍可能存在
  低阶系统性误差（如轨道残差ramp、大气长波趋势）。
  RANSAC 自动剔除局部离散点后，拟合一个空间斜面来修正这些残余。

------------------------------------------------------------
六、帕累托 (Pareto) 最优选择
------------------------------------------------------------

本脚本使用三维 Pareto 前沿从多个 (λ, model) 组合中选出最佳配置:

【三目标】
  Obj_1 = wrmse_diff    -- 两轨差分残差（越小越好）
  Obj_2 = wrmse_1       -- 轨1内部拟合残差（越小越好）
  Obj_3 = wrmse_2       -- 轨2内部拟合残差（越小越好）

【选择准则】
在 Pareto 前沿上，选取到理想点 (0,0,0) 欧氏距离最近的解:

  best = argmin sqrt( wrmse_diff^2 + wrmse_1^2 + wrmse_2^2 )

【同轨模式的双重保险】
  1. 绝对精度检查: 若 Const 模型的 wrmse_diff < 0.01 m/yr (3mm)，
     则强制使用 Const，即认为原始数据已足够好，不需要线性校正
  2. 相对提升检查: 只有当 Linear 比 Const 提升超过 30% 时，
     才考虑使用 Linear 模型，避免因少量异常点而错误引入趋势
